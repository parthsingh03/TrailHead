🧭 TrailHead read any repo in the right order

Every repo has a trail.
Most people start at a random tree.

Open a big codebase and the first question is always the same: where do I even start? TrailHead answers it — paste a public GitHub repo and get a numbered reading path built from the repo's real import graph: README first, the entry point, the modules it actually pulls in, foundations before dependents, tests last. And an honest list of what to skip.

The URL swap

Once TrailHead lives at its own address, it works like this — take any GitHub repo URL and swap the domain:

github.com/parthsingh03/AirGap  →  trailhead.pages.dev/parthsingh03/AirGap

No sign-up, no AI guessing — the order comes from imports, entry points and file links measured in the repo itself. Public repos only for now.
